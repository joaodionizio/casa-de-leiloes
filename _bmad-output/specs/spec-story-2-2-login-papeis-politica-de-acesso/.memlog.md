- (direction) Spec exclusiva da Story 2.2; não implementar, não usar git, não avançar para 2.3. Implementação depois por bmad-build (Sonnet) em nova sessão.
- (decision) P1: JWT_SECRET obrigatório, mínimo 32 caracteres; agente nunca gera/mostra/escreve valor real; usuário configura .env e Render.
- (decision) P2: PyJWT + argon2-cffi; sem framework de autenticação.
- (decision) P3: HS256; claims sub(UUID str), role, iat, exp; sem dados pessoais; validação: assinatura, alg HS256, exp, busca no banco por sub, role do token == role do banco, senão sessão inválida.
- (decision) P4: sem APP_ENV; https -> __Host-auction_session Secure; http localhost -> auction_session sem Secure; ambos HttpOnly, SameSite=Lax, Path=/, sem Domain; nunca localStorage.
- (decision) P5: POST /api/auth/login, POST /api/auth/logout, GET /api/me.
- (decision) P6: login inválido 401 invalid_credentials, corpo idêntico para e-mail inexistente e senha errada; Argon2 contra hash de referência quando o usuário não existe; sem promessa de defesa perfeita contra timing.
- (decision) P7: logout POST público idempotente, 204, apaga o cookie do ambiente, sujeito ao guard Origin/Content-Type da 2.1; README declara token copiado válido até exp.
- (decision) P8: invalid_credentials só no login; unauthorized 401 para sem sessão/JWT inválido/expirado/usuário inexistente/incoerente; forbidden 403 papel. Sem ordem global 401->403->422 e sem middleware de autenticação; guard da 2.1 continua antes do handler.
- (decision) P9: políticas PUBLIC, OPTIONAL, AUTHENTICATED, AUCTIONEER, BIDDER por dependências; toda rota declara uma; meta-teste reprova rota sem política; exclusão pequena e documentada para docs/OpenAPI.
- (decision) P10: rotas sintéticas só nos testes para provar AUCTIONEER/BIDDER permitido/negado.
- (decision) P11: users(id UUID, email minúsculo UNIQUE normalizado no login, password_hash, role com CHECK AUCTIONEER/BIDDER); sem outros campos.
- (decision) P12: seed executável isolado; start.sh migrations -> seed -> uvicorn; UUIDs fixos; não recria nem sobrescreve; só usuários.
- (decision) P13: auctioneer@example.com, bidder1@example.com, bidder2@example.com, senha Demo123! (credenciais públicas de demonstração, documentadas).
- (decision) P14: sem override de app.openapi(); responses= por rota. Verificado no FastAPI 0.162: responses={422: ErrorResponse} substitui HTTPValidationError na rota e o componente some do schema.
- (decision) P15: tela de login com React/Vite atual, sem React Router, sem lib de teste, estado local; e-mail, senha, login same-origin, erro em português, identificação mínima, papel, logout; seguir DESIGN/EXPERIENCE/FRONTEND-WORKFLOW.
